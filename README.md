# Personal Expense Tracker

A simple Personal Expense Tracker built with HTML, CSS and JavaScript. It is designed to satisfy the SMIT assignment requirements and can be deployed directly to Netlify or GitHub Pages.

## Assignment requirements covered

- New personal expense tracker project
- Expense form with **Title, Amount and Category**
- Clean expense table
- **Add, Edit and Delete** expense functionality
- Dynamic **Total Expenses**
- SVG icons in the interface
- Two application improvements:
  1. Search + category filtering
  2. CSV export + dark mode
- Data is saved in browser localStorage so expenses remain after refresh
