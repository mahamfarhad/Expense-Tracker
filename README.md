# Personal Expense Tracker

A simple Personal Expense Tracker built with HTML, CSS and JavaScript. It is designed to satisfy the SMIT assignment requirements and can be deployed directly to Netlify or GitHub Pages.

## Assignment requirements covered

- New personal expense tracker project
- Expense form with **Title, Amount and Category**
- Clean expense table
- **Add, Edit and Delete** expense functionality
- Dynamic **Total Expenses**
- SVG icons in the interface
- Two application improvements:
  1. Search + category filtering
  2. CSV export + dark mode
- Data is saved in browser localStorage so expenses remain after refresh

## Cursor AI / YOLO Mode

Use the prompts in `CURSOR_PROMPTS.txt` inside Cursor. Take screenshots of the prompts in Cursor and submit those screenshots with the repository and live Netlify link.

## 2–3 line YOLO description for submission

YOLO Mode helped me build the Expense Tracker by generating the initial interface, form, expense table, and CRUD functionality from a natural-language prompt. I then asked Cursor AI to improve the application with search/filtering, CSV export and dark mode, making the tracker more practical and user-friendly.

## Run locally

Open `index.html` in a browser. No backend or installation is required.

## Netlify

Drag the project folder into Netlify Drop, or connect the GitHub repository to Netlify.
